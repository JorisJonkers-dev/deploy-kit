\section{Outlook}
\label{sec:outlook}

The project continues in a new repository, estate-kit, with one Rust codebase for the
compiler and an in-cluster service, and a Vue interface. The oracle files and parity
method remain: the Rust compiler must match the committed files under
\path{spec/v1/examples/}. The model-driven implementation (\path{emf/}) first served
to check the oracles. It will be retired after the grade is recorded.
