\section{Introduction and Scope}
\label{sec:introduction}

Task 0 chose the problem: generate all Kubernetes deployment files for a
cluster from one abstract model of what each application needs. For Task 1, two
metamodels were built in Ecore: the source language an author writes, and the
\emph{resolved model}, which adds every value the platform derives. OCL
constraints and an Xtext syntax complete the source language, and example models
instantiate both metamodels. Appendix~\ref{sec:handin} describes the archive
handed in with this report.

The Task 0 feedback led to a smaller scope (Table~\ref{tab:scope}) and to the
notation of Section~\ref{sec:notation}.
