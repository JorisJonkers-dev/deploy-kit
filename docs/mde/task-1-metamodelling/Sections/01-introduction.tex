\section{Introduction and Scope}
\label{sec:introduction}

The project generates Kubernetes deployment files from application
requirements. Task 1 defines two Ecore metamodels: the authored source language
and the \emph{resolved model}, which records platform-derived values. OCL
constraints, Xtext syntax and example models accompany them.
Appendix~\ref{sec:handin} describes the hand-in archive.

Table~\ref{tab:scope} sets the scope. Section~\ref{sec:notation} explains the
diagram notation.
