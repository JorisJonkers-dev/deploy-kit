\section{The Hand-in Archive}
\label{app:handin}

The archive holds \path{report.pdf}, a \path{README.md} with the steps from
Appendix~\ref{app:running}, and two folders.

\path{task-2-transformations/} is an Eclipse project for reading the models
(Table~\ref{tab:handin}), imported via \texttt{File > Import > Existing
Projects into Workspace}. It contains no Java, so the transformations do not run from
it: the resolution and the final pass call the \texttt{Hashing} library, which
the implementation plug-in registers.

\path{implementation/} holds the EMF implementation and the examples the
tests read.

opens it in the Sample Reflective Ecore Model Editor without a registered
package.

\subsection{Running the Transformations}
\label{app:running}

\begin{enumerate}
  \item In \path{implementation/emf}, run \path{./mvnw clean verify} with
  JDK~21. It builds the implementation, runs every test, and writes each
  example's models and edges under
  \path{bundles/cli/target/parity/<example>/}. It takes about four minutes.
  \item In Eclipse Modeling Tools with the QVT-Operational SDK, import
  \path{implementation/emf} via \texttt{File > Import > Existing Maven
  Projects}.
  \item Run \path{resolution.launch} in
  \path{dev.jorisjonkers.deploykit.emf.resolve}. It resolves \texttt{minimal}
  from the extents step~1 wrote.
\end{enumerate}
