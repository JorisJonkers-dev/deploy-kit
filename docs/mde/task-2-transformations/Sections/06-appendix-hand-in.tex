\section{The Hand-in Archive}
\label{app:handin}

The archive holds this report as \texttt{report.pdf}, a \texttt{README.md} with
the steps of Appendix~\ref{app:running}, and two folders:

\begin{itemize}
  \item \texttt{task-2-transformations/}, an Eclipse project for reading the
    models (Table~\ref{tab:handin}), imported with File > Import > Existing
    Projects into Workspace. It contains no Java, so the transformations do not
    run from it: the resolution and the estate pass call the \texttt{Hashing}
    library, which the implementation's plug-in registers;
  \item \texttt{implementation/}, the EMF implementation and the examples its
    tests read, from which the transformations run.
\end{itemize}

\subsection{Running the Transformations}
\label{app:running}

\begin{enumerate}
  \item In \path{implementation/emf}, run \texttt{./mvnw clean verify} with
    JDK~21. It builds the implementation, runs every test, and writes each
    example's models and edges under \path{bundles/cli/target/parity/<example>/}.
  \item In Eclipse Modeling Tools with the QVT-Operational SDK, import
    \path{implementation/emf} as existing Maven projects.
  \item Run \texttt{resolution.launch} in the project
    \path{dev.jorisjonkers.deploykit.emf.resolve}. It resolves
    \texttt{minimal} from the extents step~1 wrote.
\end{enumerate}
