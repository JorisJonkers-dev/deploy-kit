# Monitoring

A behaviour of observability: ServiceMonitors and PodMonitors, Dashboards, rule groups and Receivers of the Monitoring stack, and the external checks an Application's routes derive.

|---|---|---|

| REQ-092 | Each dashboard file an Application ships renders one `GrafanaDashboard` in its own namespace and its Project's folder, selecting the Platform's Grafana instance, with a vendored file's data source inputs mapped to the Platform's data source; a missing file, a file without a `uid`, a `uid` the estate already carries, and a dashboard with no Grafana named are refused, because Grafana keys a dashboard by its `uid` and nothing is fetched at run time | [test/model/render.test.ts](../../test/model/render.test.ts) |
