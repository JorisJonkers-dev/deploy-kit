# Processes and the Hardening Class

A behaviour of one Process's pod: its containers, sidecars, command, writable paths and Assets, its placement, GPU share, VPN attachment and Spread, its priority class and lifecycle, its Kubernetes API access and egress, and the hardening posture every container takes.
